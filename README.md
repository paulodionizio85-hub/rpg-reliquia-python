# 🗡️ A Busca pela Relíquia de Python (RPG em Texto)

Bem-vindo à **Caverna dos Algoritmos**! Este é um jogo de RPG em formato de texto, desenvolvido como um projeto prático para consolidar os fundamentos de lógica de programação.

A narrativa coloca o jogador na pele de um jovem aprendiz da lendária **Guilda de Análise e Desenvolvimento de Sistemas**, que precisa provar o seu valor resgatando um artefato perdido, utilizando apenas o seu raciocínio lógico.

---

## 🎯 Objetivo do Projeto

Este programa foi criado para colocar em prática os conhecimentos teóricos adquiridos nas disciplinas iniciais de programação. O foco principal não é a interface gráfica, mas sim a estruturação correta do pensamento computacional e o controle do fluxo de dados.

### Conceitos Técnicos Aplicados:
* **Armazenamento de Dados:** Criação e manipulação de variáveis (textos e números inteiros).
* **Entrada e Saída:** Interação com o usuário através de perguntas e exibição de mensagens no terminal.
* **Operações Matemáticas:** Cálculos de adição e subtração em tempo real para gerenciar a energia do herói e dos inimigos.
* **Estruturas Condicionais:** Uso de tomadas de decisão (`se` / `senão`) para avaliar as respostas do jogador.
* **Laços de Repetição:** Implementação de ciclos (`enquanto`) para criar sistemas de tentativas limitadas e combates contínuos até que uma condição de fim de jogo seja atingida.
* **Controle de Tempo:** Utilização da biblioteca do sistema para criar pausas dramáticas na exibição do texto.

---

## 🎮 Como Jogar

O jogo é dividido em três fases lógicas:
1. **A Ponte da Lógica:** Um desafio puramente matemático.
2. **A Porta de Pedra:** Um enigma de múltipla escolha com limite de tentativas.
3. **A Batalha Final:** Um combate por turnos baseado em repetições e diminuição de energia.

### Passo a Passo para Executar no seu Computador:

1. Certifique-se de ter a linguagem Python instalada na sua máquina.
2. Baixe o arquivo principal do jogo (`rpg_python.py`) para uma pasta no seu computador.
3. Abra o terminal (ou a linha de comando do seu sistema).
4. Navegue até a pasta onde o arquivo foi salvo.
5. Inicie a aventura digitando o comando:
   `python rpg_python.py`
6. Leia a história, use o teclado para digitar suas escolhas e aperte a tecla "Enter" para confirmar.
